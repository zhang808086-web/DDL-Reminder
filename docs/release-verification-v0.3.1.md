- Claude Code：官方 `mcp get` 显示用户级服务 Connected；CLI 只读调用返回安装版服务的本机时间。
  初始模型错误来自测试进程继承的 DeepSeek 模型环境覆盖，清理测试子进程中的这些覆盖后，
  使用原有客户端配置调用成功；未修改用户模型、供应商或 API 密钥。
- Codex：已读取用户级 stdio 配置；真实 CLI 调用 `get_local_time`，事件状态 completed。
  只为该次测试临时批准此只读工具，未修改持久审批策略。模型连接有自动重试，最终调用成功。
- DeepSeek Harness Desktop 0.2.1-rc.3：原生 Host 自动拉起安装目录中的 MCP 进程；
  使用其随附的实际 Cordis、Tools 与 MCP 客户端发现四个工具并调用本机时间成功。
  测试不是 DeepSeek 模型对话测试，不改变其账号、模型或会话数据。
