Phase4 手动验收清单

1. 启动程序
   - 运行 python -m ddl_reminder.main 能正常打开窗口
   - 窗口里有“未完成任务”和“已完成任务”两个 Tab

2. 新建任务
   - 点击“新建任务”
   - 填 title、description、deadline
   - 保存后任务出现在“未完成任务”列表
   - title 为空时不能成功创建，应该有错误提示

3. 查看任务详情
   - 双击未完成任务
   - 能打开详情窗口
   - 能看到 title、description、deadline、状态等信息

4. 修改任务
   - 在详情窗口点击“编辑”
   - 修改 title / description / deadline
   - 点击“保存”
   - 弹出确认保存窗口
   - 确认后列表内容刷新
   - 再次打开详情，看到的是修改后的内容

5. 完成任务
   - 选中未完成任务
   - 点击“完成任务”
   - 任务从“未完成任务”消失
   - 任务出现在“已完成任务”

6. 恢复任务
   - 选中已完成任务
   - 点击“恢复任务”
   - 弹出确认窗口
   - 确认后任务回到“未完成任务”

7. 删除任务
   - 未完成任务可以删除
   - 已完成任务也可以删除
   - 删除前有确认弹窗
   - 点“否”不会删除
   - 点“是”才会删除

8. 持久化验证
   - 新建几个任务
   - 完成其中一个
   - 关闭程序
   - 重新打开程序
   - 任务仍然存在
   - 未完成/已完成状态没有丢失

9. 基础异常场景
   - 没选中任务时点“完成/删除/恢复”，程序不崩溃
   - 输入非法 title 时，程序不崩溃，并提示错误
   - 修改 deadline 后，保存正常
