SQLAlchemy 2.0.51、MCP SDK 1.30.0、PyInstaller 6.21.0、Inno Setup 7。

## 结果

- 最终完整测试：147 passed，包括源码与安装版 MCP 的真实 stdio 协议调用。
- MCP：工具发现、本机时间、任务创建/查询、默认时间、非法日期/时间/标题、
  不存在任务、列表上限、跨进程持久化、两个并发客户端写入及 SQLite 完整性。
- QML：主界面、任务编辑与详情、已完成卡片、设置页、新版提示和悬浮窗拖动。
- 更新检测：版本语义比较、预发布过滤、错误响应、固定仓库地址、重试、
  检查频率和退出取消；独立联网检查成功读取 GitHub 正式版信息。
- Windows 安装验证：对最终程序文件使用独立 AppIdentity 的验证安装器，
  在临时目录安装及覆盖升级，逐一比对 1900 个文件的 SHA-256。
- 安装版 GUI 成功启动，日志无错误。
- 覆盖升级清理模拟的历史依赖；升级及卸载前后，测试数据库 SHA-256 不变。
- `pip check` 无依赖冲突，`git diff --check` 无空白错误。

所有写入任务的验证使用隔离数据库。未升级或卸载用户现有安装。
这是当前 Windows 主机上的自动化与安装验证，并非所有 Windows 版本和硬件的覆盖测试。
